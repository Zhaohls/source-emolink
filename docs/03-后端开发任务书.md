public class AnonymousNameUtil {
    private static final String[] ADJECTIVES = {
        "温暖的", "快乐的", "勇敢的", "善良的", "可爱的", 
        "安静的", "闪亮的", "温柔的", "自由的", "明亮的"
    };
    private static final String[] NOUNS = {
        "云朵", "星星", "花朵", "月亮", "海浪", 
        "微风", "阳光", "小鹿", "蝴蝶", "雨滴"
    };
    
    // 生成格式：温暖的云朵#3821
    public static String generate() {
        String adj = ADJECTIVES[new Random().nextInt(ADJECTIVES.length)];
        String noun = NOUNS[new Random().nextInt(NOUNS.length)];
        int num = new Random().nextInt(9000) + 1000;
        return adj + noun + "#" + num;
    }
}

| 方法 | 路径 | 说明 |
|------|------|------|

### 实现要点

1. **注册**：检查用户名唯一性 → BCrypt 加密密码 → 生成匿名昵称 → 入库
2. **登录**：查询用户 → BCrypt.matches 验证密码 → 生成 JWT Token → 返回用户基本信息 + Token
3. **获取用户信息**：从拦截器中获取 userId → 查询并返回（排除 password 字段）
4. **修改信息**：只更新非空字段
5. **修改密码**：验证旧密码 → BCrypt 加密新密码 → 更新

## Phase 4：DeepSeek API 集成

### DeepSeekService 实现

```java
@Service
public class DeepSeekServiceImpl implements DeepSeekService {

    @Value("${deepseek.api.key}")
    private String apiKey;
    
    @Value("${deepseek.api.url}")
    private String apiUrl;
    
    @Value("${deepseek.api.model}")
    private String model;

    private final RestTemplate restTemplate;

    /**
     * 场景1：单条日记 → AI 情绪调节建议
     */
    @Override
    public String getEmotionAdvice(String emotionType, int level, 
                                    String event, String feeling) {
        String prompt = String.format(
            "你是一名专业的心理咨询师，擅长帮助大学生管理情绪。" +
            "用户当前情绪为【%s】，强度为%d/5。\n" +
            "触发事件：%s\n" +
            "内心感受：%s\n\n" +
            "请给出温暖、积极、可操作的情绪调节建议，200字以内。" +
            "语气要亲切自然，像朋友聊天一样。",
            getEmotionLabel(emotionType), level, event, feeling
        );
        return callDeepSeek(prompt);
    }

    /**
     * 场景2：周报 → AI 情绪分析总结
     */
    @Override
    public String getWeeklyAnalysis(String weeklyDataJson) {
        String prompt = String.format(
            "你是一名心理健康分析师。以下是一名大学生一周的情绪记录数据（JSON格式）：\n" +
            "%s\n\n" +
            "请分析：\n" +
            "1. 本周整体情绪状态和波动趋势\n" +
            "2. 主要的情绪触发因素\n" +
            "3. 下周的情绪调节建议\n" +
            "控制在300字以内，语气温暖积极。",
            weeklyDataJson
        );
        return callDeepSeek(prompt);
    }

    /**
     * 调用 DeepSeek API
     */
    private String callDeepSeek(String prompt) {
        try {
            // 构建请求体
            Map<String, Object> requestBody = new HashMap<>();
            requestBody.put("model", model);
            requestBody.put("messages", List.of(
                Map.of("role", "user", "content", prompt)
            ));
            requestBody.put("max_tokens", 500);
            requestBody.put("temperature", 0.7);

            // 设置 Header
            HttpHeaders headers = new HttpHeaders();
            headers.setContentType(MediaType.APPLICATION_JSON);
            headers.setBearerAuth(apiKey);

            HttpEntity<Map<String, Object>> entity = new HttpEntity<>(requestBody, headers);
            
            // 发送请求
            ResponseEntity<Map> response = restTemplate.postForEntity(apiUrl, entity, Map.class);
            
            // 解析响应
            Map body = response.getBody();
            List<Map> choices = (List<Map>) body.get("choices");
            Map message = (Map) choices.get(0).get("message");
            return (String) message.get("content");
        } catch (Exception e) {
            // AI 调用失败时抛出业务异常，由前端提示
            throw new BusinessException(502, "DeepSeek 服务调用失败");
        }
    }
    
    private String getEmotionLabel(String type) {
        // happy→开心, calm→平静, anxious→焦虑, sad→悲伤, angry→愤怒, fearful→恐惧
    }
}
```

- 发帖/评论时直接使用 user 表的 anonymous_name

#### 帖子列表

- 支持 sort 参数：`latest`（按 created_at 降序）/ `hot`（按 like_count 降序）
- 返回时额外查询当前用户是否已点赞（isLiked）

#### 敏感词过滤

```java
@Service
public class SensitiveWordFilter {
    @Value("${sensitive.words}")
    private String sensitiveWords;
    
    private Set<String> wordSet;
    
    @PostConstruct
    public void init() {
        wordSet = new HashSet<>(Arrays.asList(sensitiveWords.split(",")));
    }
    
    /**
     * 检测内容是否包含敏感词
     * @return true=包含敏感词
     */
    public boolean containsSensitiveWord(String content) {
        return wordSet.stream().anyMatch(content::contains);
    }
}
```

- 发帖和评论时调用敏感词过滤
- 包含敏感词的内容：status 设为 0（审核中），不在前端列表展示
- 不包含敏感词的内容：status 设为 1（正常）

#### 点赞逻辑

- 查询 tree_hole_like 表是否已有记录
- 已有 → 删除记录 + post.like_count - 1
- 没有 → 插入记录 + post.like_count + 1
- 返回最新的 isLiked 和 likeCount

#### 评论逻辑

- 评论后 post.comment_count + 1
- 帖子详情接口同时返回该帖子的所有评论列表
