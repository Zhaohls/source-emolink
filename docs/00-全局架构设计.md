## 一、项目概述

EmoLink 是一款面向大学生的情绪管理平台，集 **情绪日记、AI智能分析、心理知识库、匿名树洞、随机伙伴信箱** 于一体，并配备 **管理后台** 支持用户管理、内容审核、数据概览。接入 DeepSeek API 提供 AI 情绪分析与智能建议。

## 五、统一响应格式

所有 REST API 接口返回统一 JSON 格式：

```json
{
  "code": 200,
  "message": "success",
  "data": { ... }
}
```

| code | 含义 |
|------|------|
| 200 | 成功 |
| 400 | 参数错误 |
| 401 | 未登录/Token过期 |
| 403 | 无权限 |
| 500 | 服务器内部错误 |

## 六、认证机制

1. 用户登录成功后，后端生成 JWT Token 返回（包含 userId 和 role）
2. 前端将 Token 和 role 存储在 localStorage
3. 前端每次请求在 Header 中携带：`Authorization: Bearer <token>`
4. 后端通过拦截器验证 Token，解析出 userId 注入 Controller
5. 对于 `/api/admin/**` 路径，拦截器额外检查 role=admin，非管理员返回 403
6. 白名单接口（不需要Token）：`/api/user/register`、`/api/user/login`

## 七、WebSocket 通信规范（伙伴信箱）

### 连接地址
```
ws://localhost:18011/ws?token={jwt_token}
```

### 使用 STOMP 协议

| 操作 | STOMP 目的地 | 说明 |
|------|-------------|------|
| 订阅个人消息 | `/user/queue/partner/message` | 接收配对伙伴发来的消息 |
| 订阅匹配结果 | `/user/queue/partner/match` | 接收匹配成功/结束通知 |
| 发送消息 | `/app/partner/send` | 发送消息给配对伙伴 |

### 消息体格式

```json
// 发送消息
{
  "matchId": 1,
  "content": "你好呀~"
}

// 接收消息
{
  "id": 100,
  "matchId": 1,
  "senderId": 2,
  "content": "你好呀~",
  "createdAt": "2026-04-14T16:30:00"
}

// 匹配通知
{
  "type": "MATCHED",      // MATCHED | ENDED
  "matchId": 1,
  "message": "匹配成功！开始和你的伙伴聊天吧~"
}
```

## 九、开发协作规范

### 9.1 前后端对接

- 前后端严格按 `01-接口契约文档.md` 定义的 API 进行开发
- 后端先完成接口，前端可使用 Mock 数据先行开发
- 跨域由后端 CORS 配置处理

### 9.2 代码规范

- 代码注释使用**简体中文**
- 后端包名：`com.emolink`
- 前端代码使用 Composition API (`<script setup>`)
- 所有组件/页面文件使用 PascalCase 命名

### 9.3 Git 分支策略

```
main          ← 稳定版本
├── dev       ← 开发集成
├── backend   ← 后端开发分支
└── frontend  ← 前端开发分支
```
