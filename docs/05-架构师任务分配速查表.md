## 三、关键技术决策记录

| 决策项 | 选择 | 理由 |
|--------|------|------|
| 后端端口 | 18011 | 避免与其他服务冲突 |
| 前端端口 | 18012 | 用户指定 |
| 实时通信 | WebSocket (STOMP + SockJS) | 用户指定使用 WebSocket |
| AI服务 | DeepSeek API | 用户指定 |
| 密码加密 | BCrypt | 行业标准，Spring Security 内置 |
| 认证方式 | JWT无状态Token | 前后端分离标准做法 |
| 匿名昵称 | 注册时生成，全站唯一 | 简化实现，避免每次发帖都生成 |
| 消息存储 | MySQL | 毕业设计无需 Redis 等中间件 |
| 前端状态管理 | Pinia | Vue 3 官方推荐 |
| 图表库 | ECharts 5 | 功能强大，对中文支持好 |

## 四、给数字员工的操作指令

> ⚠️ **Phase 1-8 已全部完成**，以下指令仅用于 Phase 9 管理后台的增量开发。

### 给后端工程师 (gpt5.4)：

```
你好，EmoLink 项目的 Phase 1-8 已经全部开发完成，现在需要你完成最后一个阶段：

## 任务：Phase 9 — 管理后台模块（增量开发）

请先阅读以下文档了解上下文：
1. docs/01-接口契约文档.md — 只看「第七章·管理端接口」部分（14个API）
2. docs/02-数据库设计文档.md — 只看 user 表的 role 字段和管理员账号部分
3. docs/03-后端开发任务书.md — 只看「Phase 9：管理后台模块」部分

项目路径：emolink-backend
端口：18011

### ⚠️ 重要：这是增量开发，不要修改已有功能代码！

### 你需要做的事情：

**一、数据库变更（ALTER TABLE，不要 DROP）**
1. 给 user 表新增 role 字段：ALTER TABLE `user` ADD COLUMN `role` VARCHAR(10) DEFAULT 'user' COMMENT '角色：user-普通用户 admin-管理员';
2. 插入管理员账号（密码用 BCrypt 加密 admin123）

**二、修改已有文件（仅修改必要部分，不要重写整个文件）**
1. User.java 实体类 — 新增 role 字段
2. LoginVO.java — 返回值新增 role 字段
3. UserServiceImpl.java 登录方法 — 返回时带上 role 字段；登录时检查 user.status==1
4. JwtInterceptor.java — 对 /api/admin/** 路径增加 role=admin 权限检查，非管理员返回 403

**三、新增文件**
1. AdminController.java — 14 个管理端接口
2. AdminService.java + AdminServiceImpl.java — 管理端业务逻辑
3. AdminDashboardVO.java, AdminUserVO.java 等 VO 类

### 管理端接口清单（全部在 /api/admin/** 路径下）：
- GET  /api/admin/dashboard — 数据概览
- GET  /api/admin/user/list — 用户列表
- PUT  /api/admin/user/status/{userId} — 禁用/启用用户
- GET  /api/admin/article/list — 文章列表
- POST /api/admin/article — 新增文章
- PUT  /api/admin/article/{id} — 编辑文章
- DELETE /api/admin/article/{id} — 删除文章
- PUT  /api/admin/article/status/{id} — 上架/下架
- GET  /api/admin/treehole/post/list — 帖子列表
- PUT  /api/admin/treehole/post/audit/{id} — 审核帖子
- DELETE /api/admin/treehole/post/{id} — 删除帖子
- GET  /api/admin/treehole/comment/list — 评论列表
- PUT  /api/admin/treehole/comment/audit/{id} — 审核评论
- DELETE /api/admin/treehole/comment/{id} — 删除评论

请充分利用你的 Skills（代码生成、终端命令、Web搜索等）加速开发。
完成后运行 mvn clean package 确保编译通过，并验证管理端接口可正常调用。
```

## 五、风险与注意事项

| 风险 | 影响 | 缓解措施 |
|------|------|---------|
| DeepSeek API Key 未配置 | AI建议功能不可用 | 启动前在配置文件中填入有效 Key，调用失败时直接提示错误 |
| WebSocket 连接失败 | 伙伴信箱无法实时通信 | 前端提示连接失败并提供重连按钮 |
| MySQL 未启动 | 后端无法启动 | 确保 MySQL 服务运行且 emolink 库已创建 |
| 前后端接口不匹配 | 数据无法正常流转 | 严格按接口契约文档开发，不得擅自修改 |
| 管理员账号密码哈希不匹配 | 管理员无法登录 | 后端启动时用 BCrypt 生成正确哈希值替换种子数据中的示例值 |
