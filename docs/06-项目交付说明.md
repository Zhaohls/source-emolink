# 项目交付说明

## 一、交付范围

本次交付包含以下内容：

- `emolink-backend/`：Spring Boot 后端服务
- `emolink-frontend/`：Vue 3 前端项目
- `docs/`：设计文档、接口文档、交付说明、操作手册、技术详解、运行部署说明
- `README.md`：项目总览入口

本项目已经完成用户端、管理端和数据库脚本整理，可以直接作为源代码项目交付。

## 二、当前功能状态

### 用户端

- 注册、登录、个人资料维护、修改密码
- 情绪日记新增、列表、详情、编辑、删除
- 情绪日历、情绪日报、周报
- DeepSeek 情绪建议和周报分析
- 心理知识库列表、搜索、详情、收藏
- 匿名树洞发帖、评论、点赞
- 伙伴信箱匹配、聊天、结束会话
- 首页聚合看板

### 管理端

- 管理员登录后进入管理后台
- 数据概览
- 用户管理、禁用/启用
- 文章管理、发布、编辑、上架/下架、删除
- 树洞帖子审核
- 树洞评论审核

## 三、这次交付顺手做过的整理

- 文章封面字段已经整体移除，前后台都按纯文本文章处理。
- 上传目录改成相对路径 `uploads/`，没有写死任何电脑路径。
- DeepSeek 调用失败不再静默兜底，接口会明确返回错误。
- 树洞和评论的审核逻辑改成“命中敏感词才进入人工审核，普通内容直接显示”。
- 日报、周报图表初始化时机已经修正，不会再出现容器空白但没有图的问题。
- 管理端权限在前端路由和后端拦截器两侧都做了限制。

## 六、接收方拿到项目后建议先做的事

1. 先看 `docs/09-运行部署说明.md`
2. 按文档初始化 MySQL 数据库
3. 检查 `emolink-backend/src/main/resources/application.yml` 里的数据库配置、DeepSeek Key、跨域地址
4. 启动后端，再启动前端
5. 用管理员账号登录后台做一次完整联调
