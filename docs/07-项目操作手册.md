# 项目操作手册

## 一、系统入口

### 用户端

- 登录页：`/login`
- 注册页：`/register`
- 登录后默认进入：`/dashboard`

### 管理端

- 管理员使用同一个登录页登录
- 登录成功后会自动跳转到：`/admin/dashboard`

普通用户即使手动输入管理端地址，也会被前端路由守卫拦回用户首页；后端同样会做二次校验。

## 二、普通用户使用流程

### 1. 注册和登录

1. 打开登录页，点击“建立档案”
2. 输入用户名、密码、昵称完成注册
3. 返回登录页输入账号密码
4. 登录成功后系统会保存 token，并加载当前用户资料

### 2. 记录情绪日记

1. 进入“记录当下”
2. 选择情绪类型和强度
3. 填写触发事件、内心感受
4. 提交后后端会调用 DeepSeek 生成调节建议
5. 日记会出现在“我的足迹”里

补充说明：

- 如果 DeepSeek 调用失败，保存接口会直接报错，前端会弹出失败提示。
- 情绪感受为空时，后端不会放行。

### 3. 查看情绪日报和周报

#### 日报

1. 进入“情绪日报”
2. 选择某一天
3. 页面会展示当天摘要和情绪强度波动图

#### 周报

1. 进入“情绪周报”
2. 选择某一周
3. 页面会展示七日情绪波动、本周情绪分布和 AI 分析

使用时要注意：

- 选中的日期或周如果没有日记数据，页面会显示空状态
- 周报 AI 分析来自 DeepSeek，不是本地模板文案

### 4. 使用心理知识库

1. 进入“心理知识库”
2. 可以按分类浏览，也可以直接搜索关键词
3. 打开文章详情后，系统会自动增加阅读量
4. 点击收藏后，可在“我的收藏”中查看

当前知识库文章不使用封面图，管理后台新增文章时也不需要上传封面。

### 5. 使用匿名树洞

1. 进入“匿名树洞”
2. 发布帖子后，系统会根据敏感词检测结果决定是否直接显示
3. 浏览他人帖子可以点赞、评论
4. 进入帖子详情可以查看评论列表

审核规则：

- 普通内容：直接显示
- 命中敏感词：状态记为“待审核”，需要管理员处理后才会公开

评论也遵循同样的规则，所以“评论发布后是否立刻显示”取决于是否命中敏感词。

### 6. 使用伙伴信箱

1. 进入“伙伴信箱”
2. 点击加入匹配
3. 当另一位不同账号的用户也加入时，系统会完成配对
4. 匹配成功后进入聊天页
5. 任意一方结束对话后，本轮会话结束

测试时要注意两点：

- 不能用同一个账号和自己匹配
- WebSocket 依赖后端 `/ws` 端点，如果后端没启动，聊天不会建立

## 三、管理员使用流程

### 1. 登录后台

1. 使用管理员账号登录
2. 系统识别 `role=admin`
3. 自动跳转到管理后台首页

### 2. 数据概览

管理首页可以查看：

- 总用户数
- 今日新增用户
- 日记总数、今日日记数
- 文章总数
- 帖子总数和待审核帖子数
- 评论总数和待审核评论数
- 近七天用户趋势
- 全站情绪分布

### 3. 用户管理

1. 进入“用户管理”
2. 可按关键词、状态筛选
3. 点击禁用/启用修改用户状态

规则：

- 管理员不能禁用自己
- 被禁用的用户无法登录

### 4. 文章管理

1. 进入“文章管理”
2. 可新增、编辑、删除文章
3. 支持上架和下架
4. 编辑页左侧输入 Markdown，右侧实时预览

当前文章只维护标题、分类、正文、状态，不含封面字段。

### 5. 树洞帖子审核

1. 进入“帖子审核”
2. 按状态切换列表
3. 对待审核帖子执行通过、违规或删除

### 6. 树洞评论审核

1. 进入“评论管理”
2. 按状态查看评论
3. 对待审核评论执行通过、违规或删除

评论审核会同步维护帖子评论数，管理员操作后前台数据会跟着变化。

## 四、常见操作场景

### 场景 1：验证敏感词审核

1. 普通用户发布一条正常帖子
2. 帖子会直接在前台显示
3. 再发布一条包含敏感词的帖子
4. 该帖子不会在前台公开列表出现
5. 管理员进入帖子审核页处理后，前台才会有对应变化

### 场景 2：验证禁用用户

1. 管理员在后台禁用某个用户
2. 该用户再次登录时，后端会返回“账号已被禁用”
3. 管理员重新启用后，该用户才可正常登录

### 场景 3：验证伙伴匹配

1. 准备两个不同账号
2. 两个账号分别进入匹配页
3. 第二个账号加入后即可完成匹配
4. 进入聊天页测试消息收发

## 五、排障建议

### 日报或周报没有图

先确认当前日期或当前周是否真的有情绪日记数据。

### 树洞内容发出后看不到

优先检查是否命中敏感词，命中后会进入待审核状态。

### 文章发布成功但前台没看到

确认文章状态是否为“上架”。下架文章不会出现在用户端列表。

### 管理员登录后没有跳到后台

先看登录返回的 `role` 是否为 `admin`，再看本地 token 是否过期。
