### 📐 设计驱动的开发流程（必须遵守）

> **⚠️ 重要：不要直接盲写代码！每个页面/模块必须遵循以下流程：**

```
Step 1: 📝 阅读页面需求和布局规范
         ↓
Step 2: 🎨 启用「UI/UX Pro Max」Skill，输出该页面的：
         - 详细配色方案 & 设计 Token
         - 组件层次结构 & 间距定义
         - 交互状态（hover/active/disabled）
         - 动画/过渡效果规格
         ↓
Step 3: 🖼️ 使用「Claude Artifacts」生成可交互的 HTML/CSS 原型
         - 在 Artifacts 面板中实时预览效果
         - 调整布局、配色、动画，直到视觉效果满意
         ↓
Step 4: 🎨 （可选）对于核心页面，用「图片生成」Skill 输出高保真设计稿
         作为最终视觉基准
         ↓
Step 5: 💻 参照 Artifacts 原型 + 设计稿，转写为 Vue 3 组件代码
         - 复用 Artifacts 中验证过的 CSS 样式
         - 适配 Element Plus 组件体系
         ↓
Step 6: 🖥️ 使用「浏览器」Skill 打开前端页面预览实际效果
         ↓
Step 7: 📸 使用「截图」Skill 截取实际效果
         ↓
Step 8: 🔄 对比截图与原型/设计稿，调整样式直到还原度满意
```

### 💡 各 Skill 协作示例


### 1.5 Axios 实例封装 — `api/request.js`

```javascript
import axios from 'axios'
import { ElMessage } from 'element-plus'
import router from '@/router'

const request = axios.create({
  baseURL: '/api',
  timeout: 30000,
})

// 请求拦截器：注入 Token
request.interceptors.request.use((config) => {
  const token = localStorage.getItem('token')
  if (token) {
    config.headers.Authorization = `Bearer ${token}`
  }
  return config
})

// 响应拦截器：统一错误处理
request.interceptors.response.use(
  (response) => {
    const res = response.data
    if (res.code !== 200) {
      ElMessage.error(res.message || '请求失败')
      if (res.code === 401) {
        localStorage.removeItem('token')
        router.push('/login')
      }
      return Promise.reject(new Error(res.message))
    }
    return res
  },
  (error) => {
    ElMessage.error('网络异常，请稍后重试')
    return Promise.reject(error)
  }
)

export default request
```

## Phase 7：伙伴信箱模块（WebSocket）

### 7.1 WebSocket 连接管理 — `utils/websocket.js`

```javascript
import { Client } from '@stomp/stompjs'
import SockJS from 'sockjs-client'

class WebSocketClient {
  constructor() {
    this.client = null
    this.connected = false
    this.onMessageCallback = null
    this.onMatchCallback = null
  }

  connect(token) {
    this.client = new Client({
      webSocketFactory: () => new SockJS('/ws'),
      connectHeaders: { Authorization: `Bearer ${token}` },
      onConnect: () => {
        this.connected = true
        
        // 订阅个人消息
        this.client.subscribe('/user/queue/partner/message', (message) => {
          const data = JSON.parse(message.body)
          if (this.onMessageCallback) this.onMessageCallback(data)
        })
        
        // 订阅匹配通知
        this.client.subscribe('/user/queue/partner/match', (message) => {
          const data = JSON.parse(message.body)
          if (this.onMatchCallback) this.onMatchCallback(data)
        })
      },
      onDisconnect: () => {
        this.connected = false
      },
      onStompError: (frame) => {
        console.error('WebSocket error:', frame)
      },
    })
    
    this.client.activate()
  }

  sendMessage(matchId, content) {
    if (this.connected) {
      this.client.publish({
        destination: '/app/partner/send',
        body: JSON.stringify({ matchId, content }),
      })
    }
  }

  disconnect() {
    if (this.client) {
      this.client.deactivate()
    }
  }
}

export default new WebSocketClient()
```

### 9.7 登录页角色跳转逻辑

登录成功后，根据返回的 `role` 字段跳转不同页面：

```javascript
// LoginPage.vue 登录成功后的处理
const handleLogin = async () => {
  const res = await login(form)
  localStorage.setItem('token', res.data.token)
  localStorage.setItem('role', res.data.role)
  
  if (res.data.role === 'admin') {
    router.push('/admin/dashboard')  // 管理员→管理后台
  } else {
    router.push('/dashboard')        // 普通用户→用户端首页
  }
}
```
