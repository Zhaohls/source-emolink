# EmoLink 前后端接口契约文档

> **本文档是前后端开发的唯一对接标准，双方必须严格遵守。**  
> 所有接口基础路径：`http://localhost:18011/api`  
> 认证方式：Header `Authorization: Bearer <token>`（标注🔓的接口无需Token）

---

## 通用说明

### 统一响应体

```json
{
  "code": 200,
  "message": "success",
  "data": null
}
```

### 分页请求参数

| 参数 | 类型 | 说明 |
|------|------|------|
| pageNum | int | 页码，从1开始 |
| pageSize | int | 每页条数，默认10 |

### 分页响应格式

```json
{
  "code": 200,
  "message": "success",
  "data": {
    "records": [],
    "total": 100,
    "pageNum": 1,
    "pageSize": 10,
    "pages": 10
  }
}
```

## 一、用户模块 `/api/user`

### 1.1 🔓 用户注册

```
POST /api/user/register
```

**请求体：**
```json
{
  "username": "zhangsan",
  "password": "123456",
  "nickname": "小张"
}
```

**响应：**
```json
{
  "code": 200,
  "message": "注册成功",
  "data": null
}
```

**错误码：**
- 400: 用户名已存在 / 参数不合法

---

### 1.2 🔓 用户登录

```
POST /api/user/login
```

**请求体：**
```json
{
  "username": "zhangsan",
  "password": "123456"
}
```

**响应：**
```json
{
  "code": 200,
  "message": "登录成功",
  "data": {
    "token": "eyJhbGciOiJIUzI1NiJ9...",
```

## 二、情绪管理模块 `/api/emotion`

### 2.1 新增情绪日记

```
POST /api/emotion/diary
```

**请求体：**
```json
{
  "emotionType": "anxious",
  "emotionLevel": 4,
  "triggerEvent": "明天有重要考试",
  "feeling": "感觉很紧张，心跳加速，无法集中注意力..."
}
```

> **emotionType 枚举值：** `happy`(开心), `calm`(平静), `anxious`(焦虑), `sad`(悲伤), `angry`(愤怒), `fearful`(恐惧)  
> **emotionLevel：** 1-5 整数，1最轻 5最重

**响应：**
```json
{
  "code": 200,
  "message": "保存成功",
  "data": {
    "id": 1,
    "emotionType": "anxious",
    "emotionLevel": 4,
    "triggerEvent": "明天有重要考试",
    "feeling": "感觉很紧张...",
    "aiSuggestion": "考前焦虑是很正常的情绪反应。建议你先做3次深呼吸...",
    "createdAt": "2026-04-14T16:30:00"
  }
}
```

> **注意**：保存日记后，后端自动调用 DeepSeek API 生成 `aiSuggestion`，一并返回。若AI调用失败，返回默认建议文案。

---

| pageNum | 否 | 页码，默认1 |
| pageSize | 否 | 每页条数，默认10 |
| emotionType | 否 | 情绪类型筛选 |
| startDate | 否 | 开始日期 yyyy-MM-dd |
| endDate | 否 | 结束日期 yyyy-MM-dd |

**响应：**
```json

  "code": 200,

      {

    "pageSize": 10,
```
