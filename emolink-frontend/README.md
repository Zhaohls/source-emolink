# 前端项目说明

这是 EmoLink 的前端工程，技术栈为 Vue 3、Vite、Element Plus、Pinia、Vue Router 和 ECharts。

## 常用命令

```bash
npm install
npm run dev -- --host 0.0.0.0 --port 18012
npm run build
```

## 运行依赖

- 需要后端服务先启动
- 默认通过 `http://localhost:18011` 访问后端接口
- WebSocket 默认连接 `/ws`
